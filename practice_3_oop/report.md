## Доработка индивидуального проекта

В практической работе доработан проект "Система учета заказов клининговой
компании". Основные сущности предметной области представлены классами:
`Client`, `Cleaner` и `CleaningOrder`.

Класс `Client` хранит данные клиента: идентификатор, имя, телефон и адрес.
Класс `Cleaner` хранит данные сотрудника: идентификатор, имя, специализацию и
рейтинг. В нем реализован статический метод проверки рейтинга и метод проверки
соответствия специализации типу уборки. Класс `CleaningOrder` описывает заказ и
связывает объект клиента с объектом уборщика. Заказ хранит дату, тип уборки,
стоимость и состояние отмены.

Функции проекта переработаны для работы с коллекциями объектов. При создании
заказа выполняется поиск клиента и уборщика, проверяется специализация уборщика
и его доступность на выбранную дату. Отмена заказа выполняется через метод
объекта `cancel()`, а состояние заказа доступно через свойство `status`.

Данные продолжают храниться в JSON-файлах. При загрузке JSON-записи
преобразуются в объекты классов, а при сохранении объекты снова переводятся в
словарный формат. Это сохраняет простоту хранения данных и одновременно
позволяет использовать объектную модель в коде.

## Результат работы

В результате выполнения практической работы основные сущности проекта
представлены классами и объектами. Для классов реализованы атрибуты, методы,
конструкторы `__init__` и строковое представление `__str__`. Организовано
взаимодействие объектов: заказ хранит ссылки на клиента и уборщика. Основная
функциональность проекта сохранена и адаптирована к объектной модели.

Для проверки работы подготовлены автоматизированные тесты. Они проверяют
создание объектов, строковое представление, отмену заказа, повторное
использование уборщика после отмены заказа, создание заказа и преобразование
JSON-данных в объекты.
