# Сервис поиска мест по интересам

Практическая работа 3 продолжает индивидуальный проект и переводит основные
сущности предметной области в объектно-ориентированную модель.

## Основные классы

- `User` — пользователь сервиса с именем и набором интересов.
- `Category` — категория места, соответствующая направлению интереса.
- `Place` — место с категорией, адресом, рейтингом и признаком доступности.
- `Recommendation` — рекомендация, связывающая пользователя с подходящим местом.

## Что изменено в ПР3

- Основные сущности представлены классами.
- В каждом классе реализован конструктор `__init__`.
- Для объектов реализовано строковое представление `__str__`.
- Поведение перенесено в методы объектов: работа с интересами пользователя,
  проверка категории места, отмена рекомендации, преобразование объектов в словари.
- Рекомендация хранит объекты `User` и `Place`, а место хранит объект `Category`.
- JSON-загрузка создаёт объекты, а JSON-сохранение переводит объекты обратно в словари.
- Тесты адаптированы к объектной модели.

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
python -m unittest discover -s tests -v
```

Если установлен `pytest`, можно запустить:

```bash
pytest -v
```
