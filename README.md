# Сервис поиска мест по интересам

Консольное приложение для подбора интересных мест пользователям на основе их
интересов: просмотр категорий, поиск мест, фильтрация по рейтингу и формирование
персональных рекомендаций.

## Назначение

Приложение помогает пользователям находить места, которые соответствуют их
интересам. Сервис сопоставляет интересы пользователя с категорией места, учитывает
рейтинг и доступность места, после чего формирует рекомендацию.

## Целевая аудитория

- пользователи, ищущие места для отдыха, спорта, обучения или досуга;
- администраторы сервиса, ведущие каталог мест и категорий;
- партнёры и владельцы мест, которым важна заинтересованная аудитория.

## Предметная область

Поиск мест по интересам требует учёта четырёх связанных сущностей: пользователей,
категорий, мест и рекомендаций. Пользователь хранит свои интересы, место относится
к одной категории, а рекомендация связывает пользователя с подходящим местом.

## Основные сущности

- Пользователь — участник сервиса с именем и набором интересов.
- Категория — направление интереса, например «Музыка», «Спорт», «Наука».
- Место — объект каталога с названием, категорией, адресом, рейтингом и доступностью.
- Рекомендация — связь пользователя с местом, подобранным под его интересы.

## Возможности

- просмотр пользователей и добавление интересов;
- просмотр категорий мест;
- просмотр мест с названием категории, адресом, рейтингом и статусом доступности;
- поиск мест по категории;
- фильтрация мест по минимальному рейтингу;
- сортировка мест по рейтингу;
- подбор мест по интересам пользователя;
- создание и отмена рекомендации;
- сохранение и загрузка данных в JSON-файлах между запусками программы.

## Формат данных

Пользователи (`data/users.json`) — список словарей вида
`{"id": 1, "name": "Иван Петров", "interests": ["Музыка", "Кино"]}`.

Категории (`data/categories.json`) — список словарей вида
`{"id": 1, "name": "Музыка", "description": "Концерты и музыкальные площадки"}`.

Места (`data/places.json`) — список словарей вида
`{"id": 1, "name": "Джаз-клуб Север", "category_id": 1, "address": "ул. Музыкальная, 12", "rating": 8, "is_available": true}`.

Рекомендации (`data/recommendations.json`) — список словарей вида
`{"id": 1, "user_id": 1, "place_id": 1}`.
